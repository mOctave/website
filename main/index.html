Trivial

A recent project of mine, using NodeJS, Express, and Mongoose to create a competitive multiplayer trivia quiz. Now you, too, can compete for the title of ultimate party bore.

Blended Ships

Blended Ships is by far my largest and most polished ES plugin, attempting to introduce some element of realism (sorry Azure) into ship splicing.

Bitwise

Bitwise is a novel RISC simulator designed to provide a stepping stone between simple graphical demos and more complicated technical systems. It provides both a GUI and CLI to allow the user to write, execute, and understand the instructions a simple computer could use to process data.
