Blogging Like it's 2003

29 July 2026

Well, I've been meaning to make my blog a bit more accessible by adding in some nice styling (please, who likes looking at a whole page of unformatted links these days) and RSS support... so I did it.

At this point, I should maybe consider autogenerating bits of my website somehow, since I now need to remember to manually change four different things every time I add a new blog post.

Oh well, I guess. In case you didn't read the title I'm stuck twenty-three years in the past. Plus, of course, I don't want to have to restart yet another node server every time the box in my basement conks out, and I'm still too lazy to learn how to set up proper services. Manually editing HTML is a really in-demand skill these days, right?

Still, even if it's mostly pointless, learning how to manually edit RSS files was a bit of fun and might come in handy some day. And even if it doesn't, at least the links you're staring at have just become slightly less ugly.

Enjoy.
